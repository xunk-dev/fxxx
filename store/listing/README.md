# Store listing

One folder per language, named like the Android resource folders. Each has `title.txt` (30 characters max), `short_description.txt` (80 max) and `full_description.txt` (4000 max). `default` is English.

Play Console locale codes: `ar`, `bn-BD`, `cs-CZ`, `de-DE`, `es-419`, `fa`, `fil`, `fr-FR`, `hi-IN`, `id` (folder `in`), `it-IT`, `ja-JP`, `ko-KR`, `ms`, `nl-NL`, `no-NO` (folder `nb`), `pl-PL`, `pt-BR`, `ro`, `ru-RU`, `sv-SE`, `th`, `tr-TR`, `uk`, `ur`, `vi`, `zh-CN` (folder `zh`), `zh-TW` (folder `zh-rTW`). Central Kurdish (`ckb`) is not a Play Console language: the text is kept for other stores.

The texts were written without a native review.
